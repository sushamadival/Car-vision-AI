# CarVision AI 🚗

CarVision AI is an AI-powered Android application that identifies a car's make, model, and colour from an image.

## How to Run the App

1. Download or clone this repository.
2. Open the project in Android Studio.
3. Wait for Gradle Sync to complete.
4. Connect an Android phone or start an Android Emulator.
5. Click the **Run ▶** button in Android Studio.
6. The CarVision AI app will open on the connected device.
7. Select or capture a car image.
8. The AI will analyze the image and display the car's make, model, and colour.

## Technologies Used

- Kotlin
- Android
- Jetpack Compose
- AI Image Analysis
- Android Studio

## Project Features

- Select car image from gallery
- Capture car image using camera
- AI-based car detection
- Identify car make
- Identify car model
- Identify car colour
